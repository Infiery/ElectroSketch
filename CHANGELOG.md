# Change notes

## 0.8.5 - Initial public package

- Includes the current learning playground, connector library, notes, topology files, and simplified multimeter.
- Includes the text-rotation/canvas-pan fix: the rotate handle is inside the text selection boundary, and captured object gestures take priority over background panning.
- Adds public build instructions, current technical documentation, safety limitations, an MIT license, and build-output exclusions.
- Removes workstation-specific documentation from the public package and omits compiler debug symbols/local source paths from the release build.

The project evolved through earlier private versions. This repository starts with the current snapshot; it does not contain a reconstructed Git history or independently verified release notes for every earlier version.
