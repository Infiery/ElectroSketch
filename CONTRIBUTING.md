# Contributing

Thanks for taking an interest in ElectroSketch. This is a student learning project developed with extensive AI assistance. Bug reports, ideas, and small code improvements are welcome.

## Bugs and ideas

Use this repository's Issues tab. For a bug, include the version, steps to reproduce it, expected behavior, and what happened instead. For an idea, describe what you are trying to do and how the change would help. Search existing issues first when possible.

Check screenshots, notes, logs, and topology files for personal information before attaching them. Logs may include local file paths. Report electrical-model mistakes as simulator behavior; do not reproduce a dangerous circuit in real hardware to prove a bug.

## Code changes

Small pull requests are welcome. Discuss larger features or architectural changes in an issue first so expectations are clear. Keep changes focused, explain the resulting behavior, and run the relevant build/smoke checks described in the README. Include a regression check when it meaningfully tests a behavioral fix. Be candid about AI assistance and how you verified the result.

Contributed project code is covered by the repository's MIT license. Do not submit third-party assets or copied code unless you have permission and include the required attribution/license information.

## Expectations

Be respectful and patient. I maintain this in my spare time while learning; I cannot guarantee a response time, a fix, or a release date. Issues are a place to discuss the app and its models, and are not a service for approving the safety of physical electrical work.
